# SQL Practical Questions

### 1. Create a Student Database

* Create a database named `TrainingDB`.
* Select the database for use.
* Create a table called `Students` with:

  * StudentID
  * Name
  * Age
  * Course
  * Marks

---

### 2. Insert Student Records

* Insert 5 student records into the `Students` table.
* Display all records.

---

### 3. Find Top Performer

Using the `Students` table:

* Display the student with the highest marks.
* Display only Name and Marks.

---

### 4. Course-wise Filtering

Using the `Students` table:

* Display all students enrolled in "Data Science".
* Display students whose marks are greater than 75.

---

### 5. Update Student Information

* Update the marks of one student.
* Verify the changes using a SELECT query.

---

### 6. Employee Table Challenge

Create a table named `Employees` with:

* EmpID
* EmpName
* Department
* Salary

Insert at least 5 records.

Then:

* Display employees earning more than ₹50,000.
* Sort salaries in descending order.

---

### 7. Aggregate Functions

Using the `Employees` table:

* Find:

  * Highest salary
  * Lowest salary
  * Average salary
  * Total employees

---

### 8. Group By Practice

Using the `Employees` table:

* Display the number of employees in each department.
* Display the average salary department-wise.

---

### 9. Create and Join Tables

Create another table:

`Departments`

* DeptID
* Department
* Location

Insert records.

Perform an INNER JOIN between:

* Employees
* Departments

Display:

* Employee Name
* Department
* Location

---

### 10. Mini SQL Challenge

Create a table named `Products` with:

* ProductID
* ProductName
* Category
* Price

Insert at least 5 records.

Write queries to:

* Find the most expensive product.
* Find all products costing less than ₹1000.
* Count total products.
* Display products sorted by price.
