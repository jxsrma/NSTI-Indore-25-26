
# Create Table

```sql
CREATE TABLE Sales (
    SaleID INT,
    ProductName VARCHAR(50),
    Category VARCHAR(30),
    Quantity INT,
    Price INT,
    SalesPerson VARCHAR(50),
    City VARCHAR(30)
);
```
